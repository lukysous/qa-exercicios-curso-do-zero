## Destaques

- 🐞 **Bug de segurança no login:** a mensagem de erro revela quais usuários existem no sistema ([Módulo 3](modulo-3-fluxo-completo-login)).
- 🛒 **Erro de cálculo no carrinho:** o Grand Total cobrava $100,00 a mais ([Módulo 5](modulo-5-dia-a-dia)).
- 🤖 **Primeira automação:** teste de login em Cypress, passando ([Módulo 6](modulo-6-ferramentas)).
- 🔍 **Investigação além da tela:** erros de JavaScript e de requisição investigados no Console e na aba Network ([Módulo 4](modulo-4-observabilidade)).
